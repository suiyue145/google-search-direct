# Google 搜索直达 · 一键安装助手（macOS）

双击 `一键安装-Mac.command` 即可：自动下载 GitHub 最新版插件、解压到固定目录、打开 Chrome 扩展页，并把目录路径复制到剪贴板。

## 为什么还需要手动点一下？

Chrome 137+ 已彻底禁止第三方扩展静默安装（`--load-extension` 命令行参数被移除，CRX 拖拽也不可用）。任何声称"无需开发者模式一键安装"的第三方脚本都已失效。因此脚本把能自动化的部分全做了，只留下 Chrome 强制要求用户亲自确认的一步。

## 使用步骤

1. 双击 `一键安装-Mac.command`，选择 `1) 安装 / 重装`
2. 脚本完成后 Chrome 会打开 `chrome://extensions`，且路径已在剪贴板
3. 开启右上角「开发者模式」
4. 点「加载已解压的扩展程序」
5. 在文件选择窗口按 `Shift+Command+G`，按 `Command+V` 粘贴路径，回车，再点「选择」

以后要升级：再次双击脚本选 `2) 更新`，然后到扩展页点该卡片上的「重新加载」按钮即可。

## 菜单说明

| 选项 | 作用 |
|---|---|
| 1) 安装 / 重装 | 下载 GitHub 最新版，覆盖安装到固定目录并备份旧版 |
| 2) 更新已安装的插件 | 同上，但给出"重新加载"的升级提示 |
| 3) 显示插件目录 / 复制路径 | 查看已安装版本和路径，方便手动重新加载 |
| 4) 卸载 | 删除本地插件文件（浏览器里的扩展卡片仍需手动删除） |
| 0) 退出 | — |

## 安装位置与备份

- 插件目录：`~/Library/Application Support/Google Search Direct/plugin`
- 版本信息：`~/Library/Application Support/Google Search Direct/install-info.txt`
- 旧版备份：`~/Library/Application Support/Google Search Direct/backup/`（保留最近两份）

> 重要：不要删除或移动插件目录，否则 Chrome 里的扩展会失效。开发模式下每次打开浏览器出现"请停用开发者模式"提示属于正常现象。

## 如果脚本报错

- `curl` / `unzip` 缺失：macOS 通常自带；若缺失可用 Homebrew 安装
- 下载失败：检查网络，或手动访问 https://github.com/suiyue145/google-search-direct 下载 ZIP 后按 README 的 5 步安装
- 打开的不是 Chrome：脚本会依次尝试 Chrome、Edge；都没有就手动打开扩展页
