# Google 搜索直达 · 一键安装助手

一键助手会自动完成：从 GitHub 下载最新版插件 → 解压到固定目录 → 打开浏览器扩展页 → 把插件目录复制到剪贴板。只留下 Chrome 强制要求用户亲自确认的一步。

> Chrome 137+ 已移除 `--load-extension` 命令行参数，第三方扩展无法静默安装；CRX 拖拽安装也已不可用。因此最后一步必须在浏览器里点击确认，这是浏览器限制，不是脚本缺陷。

---

## Windows

### 文件

- `一键安装-Win.bat`：双击入口（负责绕过 PowerShell 执行策略）
- `install-windows.ps1`：实际安装脚本

**两个文件必须放在同一个文件夹里**，不要只拷走 `.bat`。

### 使用步骤

1. 双击 `一键安装-Win.bat`
   - 如果 Windows SmartScreen 提示“已保护你的电脑”，点「更多信息」→「仍要运行」
2. 在菜单里选 `1) 安装 / 重装`
3. 脚本完成后会自动打开 Chrome 扩展页，且插件目录已复制到剪贴板
4. 打开右上角「开发者模式」
5. 点「加载已解压的扩展程序」
6. 在弹出的文件夹选择窗口按 `Ctrl+L`，按 `Ctrl+V` 粘贴路径，回车，再点「选择文件夹」

以后升级：再次双击脚本选 `2) 更新`，然后到扩展页点该卡片上的「重新加载」按钮即可。

### Windows 菜单位置与备份

- 插件目录：`%LOCALAPPDATA%\Google Search Direct\plugin`
- 版本信息：`%LOCALAPPDATA%\Google Search Direct\install-info.txt`
- 旧版备份：`%LOCALAPPDATA%\Google Search Direct\backup\`（保留最近两份）

> 不要删除或移动插件目录，否则 Chrome 里的扩展会失效。若未找到 Chrome，脚本会尝试打开 Edge 的 `edge://extensions`。

## macOS

### 文件

- `一键安装-Mac.command`：双击入口

### 使用步骤

1. 双击 `一键安装-Mac.command`，选择 `1) 安装 / 重装`
2. 脚本完成后 Chrome 会打开 `chrome://extensions`，且路径已在剪贴板
3. 开启右上角「开发者模式」
4. 点「加载已解压的扩展程序」
5. 在文件选择窗口按 `Shift+Command+G`，按 `Command+V` 粘贴路径，回车，再点「选择」

以后升级：再次双击脚本选 `2) 更新`，然后到扩展页点「重新加载」按钮即可。

### macOS 菜单位置与备份

- 插件目录：`~/Library/Application Support/Google Search Direct/plugin`
- 版本信息：`~/Library/Application Support/Google Search Direct/install-info.txt`
- 旧版备份：`~/Library/Application Support/Google Search Direct/backup/`（保留最近两份）

## 两个系统通用的菜单

| 选项 | 作用 |
|---|---|
| 1) 安装 / 重装 | 下载 GitHub 最新版，覆盖安装到固定目录并备份旧版 |
| 2) 更新已安装的插件 | 同上，但给出「重新加载」的升级提示 |
| 3) 显示插件目录 / 复制路径 | 查看已安装版本和路径，方便手动重新加载 |
| 4) 卸载 | 删除本地插件文件（浏览器里的扩展卡片仍需手动删除） |
| 0) 退出 | — |

## 如果脚本报错

- 下载失败：检查网络，或手动访问 https://github.com/suiyue145/google-search-direct 下载 ZIP 后按 README 的手动步骤安装
- Windows 下 PowerShell 被阻止：`一键安装-Win.bat` 已使用 `-ExecutionPolicy Bypass`，正常不需要改系统策略；若公司电脑组策略禁止，请改用手动安装
- 打开的不是 Chrome：脚本会依次尝试 Chrome、Edge；都没有就手动打开浏览器扩展页
- 路径粘贴失败：脚本里选 `3)` 重新复制路径；Windows 用 `Ctrl+L`，macOS 用 `Shift+Command+G`
